# 🗺️ The 2-Axis Path Selector

Your mission depends on two factors:

| Axis | What it measures | Options |
|------|------------------|---------|
| **QA Competence** | Your role in the testing lifecycle | Manual Tester → QA Engineer → Manager → Automation → SDET → Architect |
| **AI Expertise** | How you interact with AI systems | Beginner (Scribe) → Intermediate (Assistant) → Advanced (Co-Pilot) → Expert (Architect) |

**Your combination = Official Jungle Title**

# 🎯 Your Mission (By Path Group)

### 🟢 The Scouts (Manual & Managerial)
- Analyze requirements for gaps, risks, and edge cases
- Design test cases using ≥3 ISTQB techniques
- Track budget & produce stakeholder summaries

### 🔵 The Engineers (Automation & SDET)
- Generate Playwright specs for JSON Export/Import flow
- Debug failing tests with AI assistance
- Design CI/CD pipeline with token budget limits

### 🟡 The Architects (Strategic)
- Define test pyramid & AI integration points
- Model token usage vs. quality gain
- Mentor Scouts & Engineers; produce Quality Audit report

1. Jungle Title & Path (15s)

**Judging Criteria (5-point scale):**
- AI Usage depth & structure
- Artifact quality & coverage
