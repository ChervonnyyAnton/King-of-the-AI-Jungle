# 🖥️ CLI Cheatsheet

## 🚀 Project Commands
- **Run Server:** `npx serve mock/`
- **Open App:** `open mock/index.html`
- **Lint Code:** `npx eslint mock/index.html`
- **Format Code:** `npx prettier --write mock/index.html`

## 🤖 Playwright Commands
- **Generate Code:** `npx playwright codegen http://localhost:3000`
- **Run Tests:** `npx playwright test`
- **Show Report:** `npx playwright show-report`
