# 🌿 The Legend: King of the AI Jungle

## 📖 The Scenario
You are the QA Team for a new "Configurable PDF Generator" project. The feature is complex: it handles JSON configurations, client-side logic, and print-optimization.

## 🎯 Your Objective
The "King of the Jungle" is the team that delivers the most **robust and comprehensive QA strategy**.

## 🏆 Winning Criteria
1.  **Depth**: Did you identify hidden risks (e.g., JSON injection, print errors)?
2.  **Clarity**: Is your Test Plan easy for developers to follow?
3.  **Automation**: Can the SDET Agent handle the configuration logic efficiently?
4.  **Creativity**: Did you use the Agent in a novel way?
