# 📋 WISO-1042: Export User Report as PDF

**Project:** WieKalk  
**Issue Type:** Story  
**Priority:** High  
**Status:** To Do  
**Assignee:** QA Team  

---

## 📝 Description
Users should be able to export a filtered list of cost estimates into a PDF format for offline presentation purposes.

## 🎯 Acceptance Criteria
1. **Navigation:** Add "Export PDF" button in the `CostEstimates` table view (top right).
2. **Filtering:** The PDF must reflect the current filter settings active in the UI.
3. **Data:** PDF must include columns: `Date`, `Client`, `Project Name`, `Total Estimate`.
4. **Formatting:** 
   - Professional header with company logo.
   - Date format: DD.MM.YYYY.
   - Page footer with page numbers.
5. **Performance:** Export must trigger within < 3 seconds for up to 1000 records.
6. **Error Handling:** Show toast notification on failure; log error to Sentry.

## 🧪 QA Notes / Observations
- Need to verify PDF rendering across different browsers (Chrome, Firefox, Safari).
- Check large datasets (>5000 rows) for memory leaks (Edge Case).
- Accessibility check: Is the generated PDF screen-reader friendly?
