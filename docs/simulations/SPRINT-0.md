# SPRINT-0 Simulation Template

> **⚠️ Template — create during workshop**  
> This file is a template for the Sprint-0 simulation exercise in the Architects path (F1-F4).

## Sprint-0 Simulation

### Objective
Simulate a "Sprint 0" for a QA team of 5 people using AI.

### Deliverables
1. Define roles and responsibilities for each team member
2. List daily tasks and expected artifacts
3. Forecast "Quality Velocity" (test cases per day) with vs. without AI

### Output Format
```markdown
## Roles
- Role 1: ...
- Role 2: ...

## Daily Tasks
1. ...
2. ...

## Velocity Forecast
- Without AI: X test cases/day
- With AI: Y test cases/day
```
