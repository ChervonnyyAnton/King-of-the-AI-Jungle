# 📜 Code Conventions

## 📝 Commit Messages
We follow **Conventional Commits**:
```
<type>(<scope>): <description>
# Example: feat(pdf): add print optimization
```

## 🏷 Branch Naming
`feature/TEST-<ID>-<description>`
`bugfix/TEST-<ID>-<description>`

## 💻 Code Style
- **Language:** Vanilla JS (ES6+), HTML5, CSS3.
- **Formatting:** Use Prettier.
- **Linting:** Use ESLint. No unused variables allowed.
