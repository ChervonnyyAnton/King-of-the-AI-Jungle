# Agenda: King of the AI Jungle

| Time | Phase | Content | Duration |
|------|-------|---------|----------|
| **0:00** | **Setup & Onboarding** | Troubleshooting & Environment Check (VS Code, Node.js, AI Hub configuration, AI Hub access) | 15 min |
| **0:15** | **Theory & Guided Demo** | Workshop overview, 2-Axis model explanation, sandbox app walkthrough (`mock/index.html`), debug mode intro | 30 min |
| **0:45** | **Independent Sprint** | Participants work silently on their Jungle Title path — generate artifacts, track budget | 30 min |
| **1:15** | **Debug Buffer** | Extended debugging time, instructor 1-on-1 support, peer pairing prep | 15 min |
| **1:30** | **Peer Review** | Complementary pairing across paths. Scouts review Engineers, Engineers review Architects. 15 min per pair. | 45 min |
| **2:15** | **Boss Battle** | Mixed-path teams of 3–4 diagnose 3 hidden bugs in the sandbox app (CSS, State, Security) | 15 min |
| **2:30** | **Showdown & Judges** | 3-min presentations per participant + 2 min Q&A (grouped by ~5 participants) | 15 min |
| **2:45** | **Celebration** | Awards (Scout Champion, Engineer Excellence, Architect Visionary), Jungle Crown vote, Kudos distribution | 15 min |

### ⏱ Time Management
- **Active Time:** ~155–165 minutes
- **Total Duration:** ~3 hours
- **Hard Stop:** 3:00 (flexible buffer)

### 📋 Phase Details

| Phase | Instructor Actions | Participant Actions | Exit Criteria |
|-------|-------------------|---------------------|---------------|
| **Setup** | Verify `./setup-checklist.sh` passes for each participant (see `INSTRUCTOR-QUICK-REF.md` Section 2: Resource Allocation Checklist / Ressourcen-Checkliste) | Run checklist, install dependencies if needed | All participants have `npx serve mock/` running |
| **Theory** | Walk through Path Selector, demonstrate `?debug=true`, show AGENTS.md prompt blocks | Find Jungle Title, copy path-specific prompt to scratch file | Each participant has their prompt ready |
| **Sprint** | Circulate, answer questions, track time | Execute AGENTS.md prompt, create artifacts, log in BUDGET-LOG.md | ≥1 artifact produced per participant |
| **Debug Buffer** | 1-on-1 support for participants stuck on blockers | Debug failing tests, fix selectors, ask for help | All known blockers resolved or acknowledged |
| **Peer Review** | Enforce complementary pairing (Manual ↔ Automation) | Review peer's artifacts using path-specific checklist | Both participants sign off on checklist |
| **Boss Battle** | Form mixed teams, reveal 3 hidden bugs, time 15 min | Collaborate to find & fix CSS, State, and Security bugs | All 3 bugs identified and documented |
| **Showdown** | Facilitate presentations, score using 5-point rubric | Present work (3 min + 2 min Q&A) | All participants presented |
| **Celebration** | Announce awards, lead Jungle Crown vote | Vote for Jungle Crown, receive verbal recognition | All awards distributed |
